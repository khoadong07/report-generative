# 🚀 BẮT ĐẦU TẠI ĐÂY

## Chạy source code trong 3 lệnh:

```bash
cd test
python generate_report.py
python render_html.py
```

Xong! Mở `final_report.html` để xem kết quả.

```bash

```

## Kiểm tra setup

```bash
cd test
python test_setup.py
```

Nếu tất cả ✅ thì sẵn sàng chạy!

---

## Files quan trọng

| File | Mục đích |
|------|----------|
| `.env` | API credentials |
| `config.py` | Cấu hình dates, brand |
| `generate_report.py` | Tạo JSON report |
| `render_html.py` | Render HTML |
| `test_setup.py` | Kiểm tra setup |
| `demo_without_api.py` | Demo không cần API |
