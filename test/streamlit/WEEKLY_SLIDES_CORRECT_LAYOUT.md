## RESPONSIVE BREAKPOINTS

### Desktop (> 1200px)
- 2-column layout: 50% / 50%
- Full table columns visible
- Charts at optimal size

### Tablet (768px - 1200px)
- 2-column layout: 45% / 55% (adjust based on content)
- Tables may scroll horizontally
- Charts scale proportionally

### Mobile (< 768px)
- All layouts become 1-column (stack vertically)
- Left column content appears first
- Right column content appears below
- Tables scroll horizontally
- Charts scale to fit width
